> 🎵 Доступны две сборки **1.0.0**: обычная со встроенным THE ULTRAKILL OST и **`1.0.0 (no music)`** без него. Гайд по добавлению своей музыки: [`music/HOW_TO_ADD_MUSIC.txt`](music/HOW_TO_ADD_MUSIC.txt).

Небольшой десктоп-питомец в стиле **Dynamic Island**: плашка закреплена по центру верхней части экрана поверх всех окон, реагирует на курсор, умеет показывать часы, погоду, секундомер, калькулятор и играть музыку из встроенной коллекции **THE ULTRAKILL OST**.

Проект написан на чистом HTML/CSS/JavaScript и упаковывается в Electron-приложение. Есть два варианта поставки: ** NSIS-инсталлер** (как у `Al2zTweaker`) и **портативная версия** в ZIP-архиве.

---

## Возможности

- Висит по центру сверху экрана **поверх всех окон**.
- В свёрнутом состоянии — компактная плашка `● Al2z`; автоматически сворачивается, если мышь не наводится несколько секунд.
- Нижний край «островка» тянется к курсору, а «лицо» следит за ним.
- Клик по плашке открывает панель быстрых действий.
- Пока играет музыка, в свёрнутом виде работает анимированный эквалайзер.
- Переключаемое «лицо»: обычные глаза или маскот **Claude Code**.
- Пять тем оформления: тёмная, жидкое стекло, красная, зелёная, оранжевая.
- Значок в системном трее с меню «Показать / Скрыть», «Свернуть островок», «Тестовое уведомление», «Выход».
- Глобальные горячие клавиши.
- Музыка и все ресурсы **уже встроены** в сборку — внешние папки не нужны.

### Быстрые действия

| Действие | Что делает |
|---|---|
| 📷 **Скриншот** | Делает снимок экрана и сохраняет его на рабочий стол |
| 🎵 **Музыка** | Плеер THE ULTRAKILL OST: воспроизведение, пауза, предыдущий/следующий трек |
| 🌤 **Погода** | Показывает текущую погоду |
| 🕒 **Время** | Часы и дата |
| ⏱ **Секундомер** | Старт / стоп / сброс |
| 🧮 **Счёт** | Калькулятор |
| 🎮 **Игра** | Крестики-нолики |
| 🤖 **Клод** | Переключение лица: глаза ↔ маскот Claude Code |
| ⌄ **Свернуть** | Свернуть островок в компактную плашку |

### Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl + Shift + N` | Тестовое уведомление о загрузке |
| `Ctrl + Shift + Q` | Выход из приложения |

> Выход также доступен через значок в трее → **«Выход»**.

## Установка

### Вариант 1. Инсталлер (рекомендуется)

1. Скачайте **`Al2z Island Setup 1.0.0.exe`** из раздела **Releases**.
2. Запустите его от имени администратора и подтвердите запрос UAC.
3. После установки появятся:
   - ярлык **«Al2z Island»** на рабочем столе;
   - пункт **«Al2z Island»** в меню «Пуск»;
   - запись в «Установка и удаление программ» с возможностью корректного удаления.

Инсталлер собран с помощью **electron-builder + NSIS** по тем же настройкам, что и `Al2zTweaker Setup 1.0.0.exe`: установка для всех пользователей (`perMachine`), запрос прав (`highestAvailable`), ярлыки и uninstaller.

### Вариант 2. Портативная версия

1. Скачайте **`Al2z Island portable.zip`**.
2. Распакуйте **всю папку** в любое место, например на рабочий стол:
   ```
   C:\Users\<вас>\Desktop\Al2z Island\
   ```
3. Запустите **`Al2z Island.exe`** или **`run.bat`**.

> ⚠️ Не запускайте executable прямо из окна WinRAR/7-Zip и **не копируйте только `Al2z Island.exe`** — это Electron-приложение, которому нужны соседние `DLL`, `resources`, `locales` и `music`. Именно поэтому при отправке одного `.exe` у друга ничего не происходит. `run.bat` дополнительно снимает блокировку Windows «Mark of the Web» и запускает приложение из правильной папки.

Если Windows покажет SmartScreen: **«Дополнительные сведения» → «Выполнить в любом случае»**.

## Сборка из исходников

### Требования

- Windows 10 x64
- Node.js 18+ и npm
- Electron 45.3.3 (устанавливается через `npm install`)

### Запуск в режиме разработки

```powershell
npm install
npm start
```

### Сборка портативной версии

```powershell
node build-portable.js
```

Результат: `dist\Al2z Island\`. Скрипт копирует рантайм Electron, добавляет файлы приложения и музыку из `%USERPROFILE%\Music\THE ULTRAKILL OST`, выставляет иконку и метаданные `Al2z Island.exe` через `rcedit`.

### Сборка инсталлера

```powershell
npm install --save-dev electron-builder
npx electron-builder --win
```

Результат:

```
dist-installer\
├── Al2z Island Setup 1.0.0.exe
├── Al2z Island Setup 1.0.0.exe.blockmap
├── Al2z Island portable.zip
└── win-unpacked\
```

Конфиг лежит в [`electron-builder.yml`](electron-builder.yml). Он использует локальный дистрибутив Electron (`electronDist: node_modules/electron/dist`), поэтому повторные сборки не требуют повторной загрузки Electron.

## Музыка

Поддерживаются форматы `.mp3`, `.ogg`, `.wav`, `.aac`, `.flac`, `.m4a`, `.opus`.

Приложение сначала ищет встроенную папку `resources\app\music`, а если её нет — `%USERPROFILE%\Music\THE ULTRAKILL OST`. Файлы сортируются по названию, поддерживаются переключение треков, предыдущий/следующий трек и автопереход.

> ⚠️ Из-за авторских прав сами аудиофайлы **не лежат в репозитории**. Готовые сборки в **Releases** уже содержат 13 треков; сборка **`(no music)`** — нет. Если вы собираете проект из исходников или пользуетесь версией без OST, положите файлы в `music/` либо в `%USERPROFILE%\Music\Al2z Island`. Подробности — в [`music/HOW_TO_ADD_MUSIC.txt`](music/HOW_TO_ADD_MUSIC.txt).

> Саундтрек THE ULTRAKILL OST является объектом авторского права. Перед публикацией сборки убедитесь, что у вас есть право на его распространение.

## Устранение неполадок

| Симптом | Решение |
|---|---|
| При двойном клике ничего не происходит | Запустите инсталлер или распакуйте весь ZIP; одного `.exe` недостаточно |
| Windows блокирует запуск | Свойства файла → **«Разблокировать»**, либо `Unblock-File -Path ".\Al2z Island.exe"` |
| SmartScreen предупреждает | **«Дополнительные сведения» → «Выполнить в любом случае»** |
| Антивирус удалил файл | Проверьте «Защита от вирусов и угроз → История» и восстановите из карантина |
| Ярлык не появился | Переустановите инсталлер с правами администратора |
| Нужно выйти | `Ctrl + Shift + Q` или трей → «Выход» |

Для диагностики: `Win + R` → `eventvwr.msc` → **Windows Logs → Application** — там видна причина тихого завершения процесса.
