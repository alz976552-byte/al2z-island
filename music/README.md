# THE ULTRAKILL OST

Аудиофайлы **намеренно не включены в репозиторий**, поскольку являются объектом авторского права.

Готовые сборки из раздела **Releases** уже содержат все 13 треков в `resources\app\music\`.

Если вы собираете проект из исходников или используете сборку `(no music)`, положите сюда файлы форматов
`.mp3`, `.ogg`, `.wav`, `.aac`, `.flac`, `.m4a`, `.opus`
либо в `%USERPROFILE%\Music\Al2z Island`.

Полная инструкция: [`HOW_TO_ADD_MUSIC.txt`](HOW_TO_ADD_MUSIC.txt).

Не добавляйте аудиофайлы в Git — они должны оставаться только в локальных папках и в готовых сборках.
