# Музыка

Аудиофайлы **намеренно не включены в репозиторий**.

Готовые сборки из раздела **Releases** содержат предустановленные треки в `resources\app\music\`; сборка `(no music)` — нет.

Если вы собираете проект из исходников или используете лёгкую версию, положите сюда файлы форматов
`.mp3`, `.ogg`, `.wav`, `.aac`, `.flac`, `.m4a`, `.opus`
либо в `%USERPROFILE%\Music\Al2z Island`.

Полная инструкция: [`HOW_TO_ADD_MUSIC.txt`](HOW_TO_ADD_MUSIC.txt).

Не добавляйте аудиофайлы в Git — они должны оставаться только в локальных папках и в готовых сборках.
